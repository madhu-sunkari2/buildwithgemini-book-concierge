# My agent: Procrasti-WIN
One-liner: A conversational agent that helps chronic procrastinators turn avoidance into accidental productivity with a catalog of low-friction productive detours, guilt roasts, and 2-minute gateway actions.

Tool coverage:
- Memory: Remembers user avoidance personality types, recurring avoidance triggers/excuses, energy vibe trends (Dead, Meh, Hyped, Anxious), and completed micro-wins across sessions.
- Tools: Diagnose avoidance root causes, generate/filter 5 productive detours matched to current energy level, trigger 2-minute gateway micro-tasks, and log accidental progress.
- Catalog/UI: Collection of curated productive detours (explainer videos, rubber-duck prompts, low-friction subtasks) and quiz results rendered as A2UI cards and tables.
- Image gen: Generates custom motivational anti-procrastination meme posters, visual badge rewards for completing detours, or humorous illustrations of user avoidance personas.
- Sandbox: Guilt-O-Meter score calculator, procrastination penalty vs. reward point simulator, and 2-minute momentum velocity tracker.

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): Code sandbox for Guilt-O-Meter & momentum velocity math, external API (e.g. YouTube/web search for research detours), Cloud Trace.
